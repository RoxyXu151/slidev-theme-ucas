# 学术叙事模式

叙事模式决定整场报告如何组织论点，视觉风格决定页面如何呈现。两者独立选择，同一风格可以配不同叙事模式。每份演示确定一个主模式；混合结构时写清主次，不要逐页随机切换。

## 模式选择

| mode | 适合场景 | 核心顺序 | 标题倾向 |
| --- | --- | --- | --- |
| `paper-review` | 论文阅读、文献汇报 | 研究问题 → 已有方法 → 核心改变 → 证据 → 条件与局限 → 结论 | 问题或判断句 |
| `progress-review` | 组会、周报、阶段汇报 | 目标与基线 → 已完成工作 → 证据 → 未解决问题 → 决策与下一步 | 进展、风险和决定 |
| `thesis-defense` | 开题、预答辩、学位答辩 | 背景 → 问题与空白 → 贡献 → 方法 → 验证 → 局限 → 结论与展望 | 结论与贡献 |
| `instructional` | 课程、教程、技术讲解 | 先备知识 → 概念 → 推导或示例 → 应用 → 检查理解 → 回顾 | 学习动作 |
| `neutral-briefing` | 资料汇总、会议包、状态清单 | 范围 → 分类信息 → 比较或状态 → 待决事项 → 索引 | 中性主题名 |

## paper-review

- 先说明论文试图解决的具体问题，再交代已有方法为什么不够。
- 把“论文做了什么改动”和“作者报告了什么证据”分开写。
- 主结果页围绕一个问题：哪项证据支持哪一个结论。
- 明确区分论文作者承认的局限、自己的阅读分析和尚未复现的内容。
- 结尾压缩为“问题、改变、证据、适用条件”，参考资料单独可追溯。

## progress-review

- 从上次目标或基线开始，让听众知道这次汇报在比较什么。
- 先给本阶段最重要的进展，再展开完成事项；不要按工作流水账组织。
- 每项进展说明证据、边界和是否可重复。
- 失败尝试和风险属于主线，应说明它改变了哪个后续决定。
- 结尾给出需要讨论的决定、负责人和下一步；没有决定时就写明确的后续验证。

## thesis-defense

- 开场建立问题的重要性，但尽快收束到本文要解决的单一核心问题。
- 研究空白、本文贡献和研究目标是三件不同的事，分别陈述。
- 方法页回答“为什么这样设计”，证据页回答“如何证明有效”。
- 实验设置、主结果、消融、失败案例与局限要有可追踪关系。
- 结尾总结可验证的贡献、适用边界和后续工作，避免把计划写成已完成结果。

## instructional

- 在引入新概念前交代必需背景，并按先备关系排序。
- 每页完成一个教学动作：解释、演示、对比、练习或总结。
- 抽象概念配具体例子；步骤图只承载真实顺序，不把并列信息画成流程。
- 在关键节点检查听众能否用同一规则处理新问题。

## neutral-briefing

- 目标是完整、可扫描和可查找，不强行制造结论或悬念。
- 使用中性主题标题、稳定分类和一致权重；真正重要的异常可以突出，但要说明依据。
- 表格和图用于查找、比较或状态更新，不为了视觉变化改写成叙事故事。

## 与简报和页面的关系

`brief.md` 的“叙事模式”锁定整场结构；逐页计划的“叙事阶段”说明该页承担哪一步。页面可以局部变化，但不能省略该模式要求的关键义务。若内容无法支持某个阶段，在 `brief.md` 写明原因并使用 `[待补充]`，不要用空泛页面补齐。
